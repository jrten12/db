Transform the landing page so it attracts serious, systems-oriented simulation players

CURRENT PROBLEM

The landing page currently feels like:
	•	a polished SaaS product
	•	a generic game pitch

It needs to feel like:
	•	a real system already in motion
	•	a scenario the user is stepping into
	•	something with risk, pressure, and consequence

⸻

CORE DIRECTIVE

Do NOT make it more “fun” or casual.

Make it feel:
	•	more real
	•	more tense
	•	more system-driven
	•	slightly less polished and more serious

⸻

Modify ONLY the landing page hero section.

ADD: IN-SCENARIO ENTRY

LEFT SIDE (minimal text)

Keep it tight. No fluff.

RIGHT SIDE (SYSTEM PANEL UI)

Design this like:
	•	a financial dashboard

SYSTEM PRESSURE (VISIBLE ABOVE THE FOLD)

These must be visible immediately on load.

Goal:
Create urgency and consequence before any click.

CTA (BUTTON)

Replace “Play Now” with something more committed:

stepping into an active system, not starting a demo

DEPTH SIGNALS (SUBTLE, NOT BULLET LISTS)

Without adding long explanations, visually imply:
