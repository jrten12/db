# DEALBREAK - Economic Viability Analysis
*Mathematical Assessment of Game Balance*

---

## Executive Summary

**Current State:** Game is **marginally viable** with $50K/52-week config but has critical progression blockers.

**Key Finding:** Starting capital allows purchase of 1-2 properties, but **diligence costs eat 30-40% of capital** before first deal.

## Critical Findings

### 1. Starting Capital Insufficient
- Minimum viable first deal: **$60,000-$75,000**
- Current starting capital: **$50,000**
- Deficit: **$10,000-$25,000**

### 2. Diligence is Punished, Not Rewarded
- Proper diligence costs: **$8,000-$15,000 per property**
- Players who research go bankrupt **faster** than those who gamble
- **Game incentivizes reckless play**

### 3. Time is Adequate, But Cash Isn't
- 52 weeks = sufficient for 2-3 deal cycles
- **Bottleneck is capital, not time**

### 4. Property Price Distribution is Imbalanced
| Price Tier | Count | % of Inventory | Accessible with $50K? |
|------------|-------|----------------|-----------------------|
| $125K-$165K | 4 | 31% | **Maybe** (with luck) |
| $185K-$235K | 6 | 46% | **No** (insufficient capital) |
| $275K-$285K | 3 | 23% | **Hell No** |

**Result:** Only **31% of inventory** is theoretically accessible with starting capital.

## Recommended Economic Rebalancing

### Option 1: Increase Starting Capital
```
Current: $50,000
Recommended: $80,000-$100,000

Difficulty Tiers:
  Apprentice:   $100,000 / 52 weeks
  Operator:     $75,000 / 36 weeks
  Shark:        $50,000 / 24 weeks
```

### Option 2: Reduce Diligence Costs
```
Current costs:
  Comp Analysis:      $3,000 → $1,500 (50% reduction)
  Market Rent Study:  $2,500 → $1,500
  Inspection:         $3,500 → $2,000
  Contractor Walk:    $2,000 → $1,000
  Title Search:       $1,500 → $750

Total Savings:        ~$6,000 per property
```

### Option 3: Add "Starter Tier" Properties
```
Add 3-5 properties in $90K-$120K range:
  Purchase:           $100,000
  Down Payment (20%): $20,000
  Rehab:              $5,000-$10,000
  ARV:                $125,000-$140,000

Accessible Profit:    $8,000-$15,000 per flip
Purpose:              Bootstrap capital for bigger deals
```

### Option 4: Introduce Equity Partners (NPC Investors)
```
Mechanic: Player can "partner" on first deal
  Partner provides:   50% of down payment
  Partner receives:   50% of profit
  Player retains:     100% of experience/learning

Effect:               Reduces capital barrier
                      Reduces profit (balanced trade-off)
                      Enables progression
```

### Option 5: Make Diligence Free for First Property
```
Tutorial Protection:
  First property investigated: Free diligence
  Subsequent properties:       Normal costs

Effect:               Teaches proper workflow
                      Doesn't punish new players
                      Creates positive first experience
```

```
Starting Capital:         $50,000
Minimum First Deal Cost:  $44,470 (Oakwood, no diligence)
Margin for Error:         $5,530 (11%)

Problem: First surprise cost = instant bankruptcy
```

### Error 2: Diligence Cost as % of Starting Capital
```
Full Diligence Budget:    $10,000-$15,000
Starting Capital:         $50,000
Diligence % of Capital:   20-30%

Problem: Research costs more than down payments!
```

### Error 3: Cheapest Property Has Negative ROI
```
Oakwood Cottage Best Case:  -$2,230 loss
Oakwood Typical Case:       -$9,230 loss

Problem: Even optimal play on cheapest property = loss
```

### Error 4: Accessible Property Count vs. Win Condition
```
Properties Affordable:      4 of 13 (31%)

Problem: Zero margin for error = impossible win condition
```

## Conclusion

**The game's underlying mechanics are sound**, but the **economic parameters are catastrophically miscalibrated**:

1. Starting capital is **40% too low**
2. Property prices are **30% too high** (or starter tier is missing)
3. Diligence costs are **2-3x too expensive**
4. Profit margins on accessible properties are **negative or barely positive**
5. Win condition (3 profitable deals) is **statistically impossible**

**Recommended Action:**
- Increase Apprentice mode capital to **$85,000-$100,000**
- Add 5 properties priced **$90,000-$120,000**
- Reduce diligence costs by **50%**
- Introduce tutorial/partner mechanics to bootstrap first deal

With these changes, the game becomes **challenging but fair** instead of **impossible**.
