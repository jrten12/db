Goal

Make the section feel like the start screen / campaign entry point for a real estate sim game.

It should feel:

Interactive
High-stakes
Strategic
Realistic enough to be believable
More like a game HUD than a generic landing page
Replace the current vibe

Avoid:

Giant AI-looking headline text
Overly dramatic random gradients
Generic “AI SaaS” stats
A disconnected floating dashboard card
Anything that feels like a fake product demo

Instead, make it feel like:

A game scenario card
A live campaign save file
A management sim HUD
A deal story the player is about to enter

Visual style

Make it look like a real game UI:

Use HUD-style cards and event logs
Add small icons, badges, progress indicators, and status chips
Keep the dark background and gold accent language
Use less oversized typography
Use sharper information hierarchy
Make the right panel feel attached to the section, not pasted on
Add subtle motion to ticker/event log if the app already supports animation
Keep it premium, but less cinematic and less “AI art”
Important design constraint

This section should still feel connected to the rest of the website, but it needs to be more engaging and more clearly game-like than the current version.

Do not redesign the entire app. Only update this hero/opening simulation section.
